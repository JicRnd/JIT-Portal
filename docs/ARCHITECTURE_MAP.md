## 3. SERVICE FUNCTIONS/CLASSES

### service.py
- `compute_profit()`: Calculate profit margin on working_net_each using Excel formula logic
- `quote_inputs_from_payload()`: Coerce JSON payload into QuoteInputs dataclass
- `decimal_to_json()`: Serialize Decimal to JSON-safe float or string
- `calculate_payload()`: Execute pricing engine on payload, return breakdown + dimensions
- `build_quote_draft()`: Transform calculation into draft Quote form pre-fill JSON
- `make_engine()`: Instantiate QuotePricingEngine with data from project root

### quote_service.py
- `upsert_customer()`: Insert or update Customer master directory from quote snapshot
- `create_quote_snapshot()`: Persist Quote + QuoteLineItems from calculation & payload
- `get_quote()`: Retrieve Quote by id
- `update_quote_edits()`: Merge PATCH payload into Quote (presentation + line items)
- `duplicate_quote()`: Clone Quote for new revision
- `quote_to_json()`: Serialize Quote + line_items + documents + emails to JSON

### pricing_catalog_service.py
- `import_pricing_catalog()`: Bulk import CSV pricing data into database
- `catalog_page_data()`: Build categorized parts list for UI
- `update_pricing_amount()`: Individual price field edit with audit log
- `preview_bulk_price_update()`: Simulate bulk edit effect without persisting
- `apply_bulk_price_update()`: Execute bulk edit, log all changes
- `recent_price_changes()`: List recent PriceChangeLog entries
- `restore_price_change()`: Undo a single price change by change_id
- `get_conflict_details()`: Describe conflicting price sources for a row
- `resolve_conflict()`: Accept one source, discard others
- `create_catalog_part()`: Insert new CatalogPart
- `get_catalog_part()`: Retrieve CatalogPart by id
- `update_catalog_part()`: Edit CatalogPart fields
- `parse_price_workbook()`: Extract price updates from uploaded Excel file
- `apply_workbook_price_update()`: Apply parsed Excel price updates
- `build_price_template_workbook()`: Generate downloadable Excel template

### quote_numbering.py
- `generate_quote_number()`: Generate unique quote ID as [customer_initial] + MMDDYYHHMM, retrying on collision

### current_user.py
- `get_or_create_current_user()`: Fetch or auto-create session user from request headers/cookies

### db.py
- `get_engine()`: SQLAlchemy engine for Quote.db (default)
- `get_accounts_engine()`: SQLAlchemy engine for User_accounts.db
- `get_quotes_engine()`: SQLAlchemy engine for Quote.db
- `get_orders_engine()`: SQLAlchemy engine for Order.db
- `get_pricing_engine()`: SQLAlchemy engine for Pricing.db
- `get_session_factory()`: ThreadLocal session factory
- `get_session()`: Context manager for transactional database sessions
- `init_db()`: Create all tables across all databases

### cylinder_quote_engine/engine.py
- `excel_roundup()`: ROUNDUP() Excel function equivalent
- `fmt_code_number()`: Format Decimal as integer code string
- `QuotePricingEngine`: Main pricing calculation engine class (constructor, methods unknown from this view)

### cylinder_quote_engine/data.py
- `dec()`: Convert string/number to Decimal
- `parse_dimension()`: Parse dimension input (e.g., "1.5", "1 1/2") into Decimal
- `PricingData`: Immutable pricing tables snapshot (constructor, methods unknown from this view)

## 6. Feature Flow Chains (end-to-end)

### Quote Button Flow
```
order_form.html →
app.js:$('quoteForm').addEventListener('submit') →
/api/quote/draft (POST) →
web.py:quote_draft() →
service.py:build_quote_draft() →
service.py:calculate_payload() →
employee_quote_forms.html / customer_quote_form.html
```

### Save Quote Flow
New quote:
```
quote_form.html button#saveQuoteButton →
quote_form.js:saveQuote() →
/api/quotes (POST) →
web.py:create_quote() →
quote_service.py:create_quote_snapshot() →
quote_numbering.py:generate_quote_number() →
Quote + QuoteLineItem (DB tables)
```
Order submission:
```
quote_form.js:saveQuote() [continued] →
/api/quotes/{id}/order (POST) →
web.py:submit_order_for_approval() →
Order table
```
Existing quote update:
```
quote_form.js:employeeSaveQuote() →
/api/quotes/{quote_id} (PATCH) →
web.py:update_quote() →
quote_service.py:update_quote_edits() →
Quote + QuoteLineItem (DB tables)
```

### Parts Catalog Inline Edit Flow
```
parts-catalog table cell edit →
JS fetch /parts-catalog/parts/<row_id> (POST) →
portal.py:update_parts_catalog_part() →
pricing_catalog_service.py:update_catalog_part() →
CatalogPart table + price_change_log table (audit)
```

### Employee/Customer Signup Approval Flow
Signup submission:
```
customer_signup.html / employee_signup.html →
form POST /customer/signup or /employee/signup →
portal.py:customer_signup() / employee_signup() →
portal.py:signup() →
User table (approval_status = "pending")
```
Accept/approve:
```
employee_dashboard.html (approve button) →
/approve-user/<user_id>/<decision> (POST) →
portal.py:approve_user() →
User table (approval_status → "approved", is_active=True)
```
