# Web Milestone 1 Scope

Included:
- Flask application boundary around Pricing Engine v1.2.
- Browser OrderEntry-style calculator.
- Cascading valid cylinder selections sourced from extracted pricing data.
- Common modifications, position sensing, accessories, six special-parts rows, and Standard Rod Boot.
- Customer-facing price outputs and detailed pricing breakdown.
- Legacy compatibility warnings surfaced to the user.

Not included yet:
- Customer database.
- Quote saving/history.
- Transactional quote numbers.
- Authentication/users/roles.
- PDF quote generation.
- Production WSGI hosting/deployment.

Next milestone: database-backed quote sessions and persistence so multiple users can create and save quotes concurrently.
