1. Parts Catalog and Inventory Workflow
----------------------------------------

- Added a dedicated inventory workflow backed by Inventory.db.
- Added InventoryPart support for:
	- part number;
	- product description;
	- whole-number inventory quantity;
	- allocated quantity;
	- starting 2025 quantity;
	- on-order quantity;
	- source workbook/file name;
	- employee who made the update;
	- update timestamp.
- Kept Pricing.db authoritative for catalog part identity, description,
	family assignment, and pricing information.
- Kept Inventory.db authoritative for current inventory quantities.
- Added synchronization so catalog parts receive inventory records and the
	Parts Catalog and Inventory Manager use the same inventory quantity source.
- Preserved catalog part-number changes by renaming the matching inventory
	record when a catalog part is edited.
- Added inventory source display and employee/update metadata to the
	Inventory Manager.
- Expanded inventory search/list responses so the manager can display all
	inventory rows rather than only a small initial page.
- Preserved source workbook names when inventory uploads are applied.
- Continued to preserve existing inventory rows that are absent from a new
	upload; uploads update or create mapped rows and do not delete rows.
- Inventory quantities are normalized with Decimal arithmetic and rounded
	upward to whole quantities using ROUND_CEILING.

2. Inventory Workbook Translator
--------------------------------

- Inspected the real workbook:
	2026 JIT Order Entry V3.xlsm
- Confirmed that the workbook contains an Inventory worksheet with the
	columns Part Number, Product Description, Unit Price, On Hand, Allocated,
	Start 2025, On Order, and Inventory.
- Added workbook reading through openpyxl for XLSX/XLSM files.
- XLSM files are opened with keep_vba=True so the VBA project is preserved.
- Workbook formulas are not edited or overwritten.
- The translator reads cached/displayed formula results with data_only=True.
	This allows formula-driven values such as Allocated and Inventory to be
	imported without loading Excel at application runtime.
- Unit Price is read for compatibility with the workbook format but is not
	persisted as inventory data.
- Inventory is taken from the workbook Inventory value when available.
- When Inventory is blank, the translator derives it from On Hand minus
	Allocated.
- Added support for the standalone workbook upload flow using only the
	Inventory sheet.
- Existing CSV/XLSX/XLSM upload validation and Inventory-sheet error handling
	remain in place.
- Verified the actual workbook translated 847 rows successfully.
- Verified the first workbook row translated from 5534.208 inventory to the
	whole-number value 5535 using upward rounding.
